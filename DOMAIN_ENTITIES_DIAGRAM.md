# 🔗 العلاقات بين الكيانات (Relationships)

## للرسم على الـ Diagram:

```
1. USER ──────────── AVATAR
   (1:1)            الطفل له أفاتار واحد

2. USER ──────────── PROGRESS
   (1:1)            الطفل له إحصائيات واحدة

3. USER ──────────── QUEST
   (Many to Many)   الطفل يكمل مهام كثيرة
                    المهمة يكملها أطفال كثيرة

4. ZONE ──────────── QUEST
   (1:Many)         المنطقة فيها مهام كثيرة

5. USER ──────────── BADGE
   (Many to Many)   الطفل يحصل على شارات كثيرة
                    الشارة يحصل عليها أطفال كثيرة

6. USER ──────────── SHOP ITEM
   (Many to Many)   الطفل يشتري أغراض كثيرة
   via Purchase     الغرض يشتريه أطفال كثيرة

7. USER ──────────── DONATION
   (1:Many)         الطفل يعمل تبرعات كثيرة
```

# 🎨 كيفية رسم الـ Diagram

## على Figma أو Draw.io:

### **الخطوة 1: ارسم المربعات (Entities)**
- استخدم أداة **Rectangle**
- كل كيان = مربع
- حجم موحد: **250px × 200px**

**التنسيق:**
```
┌─────────────────┐
│  🎨 اسم الكيان  │  ← Header (لون مميز)
├─────────────────┤
│ • خاصية 1       │  ← Body (أبيض)
│ • خاصية 2       │
│ • خاصية 3       │
└─────────────────┘
```

**الألوان المقترحة:**
- User: `#3b82f6` (أزرق)
- Avatar: `#ec4899` (وردي)
- Zone: `#10b981` (أخضر)
- Quest: `#f59e0b` (برتقالي)
- Badge: `#fbbf24` (ذهبي)
- Shop Item: `#8b5cf6` (بنفسجي)
- Progress: `#06b6d4` (سماوي)
- Donation: `#ef4444` (أحمر)

---

### **الخطوة 2: ارسم العلاقات (Relationships)**

استخدم أداة **Arrow** أو **Connector**

**أنواع العلاقات:**

**1:1 (واحد لواحد):**
```
[User] ═══════ [Avatar]
       1     1
```
- خط مزدوج (═) أو خط عريض
- اكتب "1" على كل طرف

**1:Many (واحد لكثير):**
```
[Zone] ───────< [Quest]
       1      *
```
- خط بسيط (─)
- "1" على جانب الواحد
- "*" أو "∞" على جانب الكثير
- سهم مفتوح (<) على جانب الكثير

**Many:Many (كثير لكثير):**
```
[User] >──────< [Badge]
       *      *
```
- سهمان مفتوحان على الجانبين
- "*" على الجانبين

---

### **الخطوة 3: ترتيب الكيانات**

**التخطيط المقترح:**

```
صف 1 (أعلى):
┌──────┐    ┌──────┐    ┌──────┐
│ User │    │Avatar│    │Progress│
└──────┘    └──────┘    └──────┘

صف 2 (وسط):
┌──────┐    ┌──────┐    ┌──────┐
│ Zone │    │Quest │    │Badge │
└──────┘    └──────┘    └──────┘

صف 3 (أسفل):
┌──────┐    ┌──────┐
│ Shop │    │Donation│
│ Item │    │       │
└──────┘    └──────┘
```

**ثم اربط بالخطوط حسب العلاقات!**
